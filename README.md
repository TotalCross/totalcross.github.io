## Setup

```sh
yarn # npm i
```
### Pull markdown files from totalcross-docs
```sh
./prepare-docs
```
## Start developing

```sh
yarn dev # npm run dev
```

## Build

```sh
yarn build # npm run build
```

## Serve built app

```sh
yarn serve # npm run serve
```
